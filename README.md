# CrystalOS #

## A clean, useful web operating system ##

### Code ###

#### C & OpenGL ####

I used them to write the animation code, which I later compiled to WASM(web assembly) and WebGL using emscriptem.


#### HTML, CSS, JS ####

I used them for the rest: structure written in HTML, styled in CSS and Java Script for the logic. 


### Style ###

I chose a liquid glass style with dark colors. I liked how the animation blended behind it.
I used darker colors since I am a fan of dark-mode.

### Links & resorces I used ###
